# ReLevel

Плагин Autodesk Revit для переноса элементов и пересоздания планов на другом уровне. В основной версии реализованы Кейс 1 — одноуровневое загружаемое семейство без хоста, Кейс 2 — вертикальные колонны и стены Basic/Curtain, Кейс 3 — семейство на грани хоста, Кейс 4 — перекрытия и фундаментные плиты класса Floor, Кейс 5 — крыши выдавливанием ExtrusionRoof, Кейс 6 — крыши по контуру FootPrintRoof без уровня среза, Кейс 7 — прямые балки с Reference Level. Реализация собрана, но перенос и операции с видами ещё требуют ручной проверки в Revit.

## Сборка и установка



**Готовые файлы всегда находятся в корневой папке `bin`. Вариантов только два.**

| Что собрать | Конфигурация в IDE | Папка результата |
| --- | --- | --- |
| Основная версия `2025+` | Release (или Debug) | `bin/2025+/` |
| Старая версия `2024-` | Legacy | `bin/2024-/` |

Обычный **Build** с Debug/Release обновляет только `2025+`. Для старой версии выберите **Legacy → Build**. Обе конфигурации создают одинаковую структуру:

```text
bin/
  2025+/
    ReLevel.addin
    ReLevel/ReLevel.Revit.dll
  2024-/
    ReLevel.addin
    ReLevel/ReLevel.Revit.dll
```

Дополнительные PDB/deps-файлы — результаты компиляции. Debug и Release используют одну папку `2025+`: в ней находится последний собранный вариант.

Из командной строки:

```powershell
dotnet build ReLevel.sln -c Release
dotnet build ReLevel.sln -c Legacy
```

Исходники основной версии — `src/ReLevel.Revit`. В `legacy/src/ReLevel.Revit` находится последняя адаптация для старых Revit (2026-09-25). Обновляем её из основной версии **только по прямому запросу пользователя**. Сборка Legacy компилирует уже адаптированные исходники и сама их не синхронизирует. Проект, решение, манифест и документация общие. Очистка обработки элементов выполнена только в основной линейке; Legacy пока сохраняет прежний код.

Для компиляции нужны SDK .NET 8 или новее, API Revit 2025 для основной версии, API Revit 2022 и .NET Framework 4.8 Developer Pack для Legacy. API по умолчанию берётся из установленного Revit соответствующего базового года; другой каталог задаётся через `-p:RevitInstallDir=...`. Выбирать каждый год не нужно. Старый параметр `RevitVersion` больше не используется.

Версия `2025+` собирается один раз на .NET 8 против API 2025 и предназначена для 2025/2026; `2024-` — один раз на .NET Framework 4.8 против API 2022 и предназначена для 2022–2024. Названия обозначают две линейки, а не обещание поддержки любых будущих или более старых Revit. В Legacy доступ к ID и встроенным параметрам адаптируется к API запущенного Revit, включая 64-битные значения 2024. Это необходимо из-за [изменений бинарной совместимости API 2024](https://blog.autodesk.io/64-bit-element-ids-maybe/).

**Проверено 2026-09-29:** основная сборка Release проходит с API Revit 2025, без ошибок и предупреждений; DLL обновлена в `bin/2025+/ReLevel`. Ранее проверялись сборка Legacy и инициализация её адаптеров с API 2022/2024 вне Revit; текущие изменения в Legacy не переносились. Проверка с API 2023 вне Revit не завершилась из-за отсутствующих зависимостей. **Запуск новой команды и операции в моделях пока не проверены**, в том числе загрузка основной DLL в Revit 2026. Компиляция основной версии не использует API установленного Revit 2026.5 и не требует для него отдельной сборки.

Установка при закрытом Revit: скопируйте содержимое подходящей папки `bin/2025+` или `bin/2024-` в `%APPDATA%\Autodesk\Revit\Addins\<год>`. В каталоге года должны оказаться `ReLevel.addin` и папка `ReLevel` с DLL. Для каждого года одной линейки используется одна и та же DLL. Библиотеки Autodesk в комплект не копируются. Команда: **Надстройки → Внешние инструменты → ReLevel**.

## Интерфейс

При переносе элементов и пересоздании видов внизу окна отображаются прогресс, число обработанных элементов или видов, текущий ID и прошедшее время. Строка обновляется между элементами или видами; на длительной операции сохраняется текущий ID. Во время операции управление и закрытие окна заблокированы.

В основной версии `2025+` при первом запуске язык выбирается по интерфейсу Revit: русский → **Русский**, английский и остальные языки → **English**. Переключатель **English / Русский** находится справа сверху; ввод текста в нём отключён. Он меняет интерфейс сразу и задаёт язык последующих диалогов и результатов. Ручной выбор сохраняется до завершения сеанса Revit, в том числе при повторном открытии команды. Имена из модели и сообщения самого Revit сохраняют исходный язык; уже сформированные результаты операций не переписываются. Версия `2024-` остаётся без этих изменений.

Окно открывается по центру экрана с начальным размером 920 × 607,2 единицы WPF. Кнопки под таблицами расположены справа. Чек-бокс в заголовке отмечает все строки или снимает отметки; частичная отметка показана промежуточным состоянием. Если выделить несколько строк через Ctrl/Shift и нажать галочку одной из них, новое состояние применяется ко всему выделению. Пробел на чек-боксе работает так же.

Верхняя строка содержит выбор исходного уровня и языка. Режим «Работать с выбранными элементами» отключён; начальное выделение Revit не ограничивает таблицы. Смена уровня сбрасывает отметки и результаты строк.

**Элементы:** показаны доступные для переноса экземпляры Кейсов 1–18, связанные с исходным уровнем. Колонка «Привязка» показывает «Уровень», «Низ», «Верх», «Низ и верх» или «Уровень спецификации». Отметьте строки, нажмите «Перенести элементы» и выберите целевой уровень. Кейс 1 меняет уровень обычного семейства и восстанавливает исходную точку размещения. Кейс 2 меняет только привязки колонны или стены к исходному уровню и компенсирует разницу отметок смещениями. Для стены с Unconnected меняется только нижняя привязка, высота сохраняется. У стены с присоединённым верхом сохраняется присоединение; компенсация смещений рассчитана на сохранение Unconnected Height. При переносе стены восстанавливаются исходные точки размещённых на ней семейств; их уровни меняются только при отдельном выборе для переноса. Кейс 3 меняет Schedule Level и компенсирует Elevation from Level у семейства на грани прежнего хоста. Кейс 4 меняет уровень перекрытия или фундаментной плиты и компенсирует Height Offset From Level. Кейс 5 меняет Reference Level крыши выдавливанием и компенсирует Level Offset. Кейс 6 меняет Base Level крыши по контуру и компенсирует Base Offset From Level. Кейс 7 меняет Reference Level балки с компенсацией обоих смещений концов; при блокировке уровня сначала пытается отсоединить балку от рабочей плоскости. «Выделить элементы» выбирает отмеченные строки в модели; «Удалить элементы» показывает состав удаления с зависимостями и запрашивает подтверждение. Требования: [SPEC — перенос элементов](docs/SPEC.md#перенос-элементов-с-уровня-на-уровень).

Результаты переноса выводятся по ID, даже если экземпляр исчез из таблицы исходного уровня. Уже целевой уровень даёт пропуск без записи. Обычная ошибка откатывает один экземпляр; критическая ошибка останавливает обработку и закрывает окно. Предыдущие успешные переносы сохраняются. Каждый перенесённый экземпляр отменяется отдельным Undo.

В обоих кейсах выполняются отбор и сам перенос; автоматического сравнения геометрии, параметров и других объектов после записи нет. Успех означает завершение транзакции. Предупреждения Revit обрабатываются обычным диалогом; ошибки API откатывают текущую операцию. Общая проверка результатов для тестирования отложена до разработки всех кейсов.

**Виды:** нешаблонные виды с `GenLevel`, равным выбранному уровню; отметка, ID, имя, тип вида и статус. Статус всегда начинается с «Поддерживается» / «Не поддерживается» и относится к пересозданию. Далее показаны причина ограничения и результат последней операции, если он есть. Отмеченные виды можно последовательно открыть (последний становится активным) или удалить после подтверждения. «Пересоздать виды» создаёт планы этажей, потолков и конструкций на другом уровне с префиксом имени, настройками, шаблоном, секущим диапазоном и аннотациями. Исходные виды и их размещения на листах сохраняются; новые виды размещаются на тех же листах поверх исходных, с тем же центром и поворотом видового экрана. Требования: [SPEC — пересоздание видов](docs/SPEC.md#пересоздание-видов); фактическое состояние и проверки: [Tasks](TASKS.md).

Поиск в обеих таблицах работает по видимым колонкам без учёта регистра. Стрелки и Enter/Shift+Enter переходят между совпавшими строками, «Фильтр» оставляет только совпадения. Пустой запрос показывает все строки. Общая отметка и операции применяются только к видимым строкам; скрытые отметки сохраняются до обновления данных, но не участвуют в операциях.

В выпадающих списках исходного и целевого уровней можно вводить часть имени: остаются только совпадения без учёта регистра, отсортированные по имени. Очистка текста показывает все варианты. Выберите уровень мышью или клавиатурой; Enter в раскрытом списке подтверждает выбор, но не запускает операцию. При ручной проверке проверьте также отсутствие совпадений, повторное открытие списка и смену исходного уровня.

Состояние существует только в памяти окна. Закрытие окна не отменяет выполненные операции; отмена — через Undo Revit. История автоматически не записывается в файлы или параметры проекта. Журнал пересоздания видов можно явно сохранить в `.txt`.

Пересоздание сохраняет новый вид до копирования настроек и содержимого. Ошибки последующих этапов и диагностические замечания показываются в отдельном журнале и обычно не отменяют вид. В журнале доступны исходные ID проблемных элементов, подробности Revit, поиск, копирование, сохранение и открытие нового вида. Ошибка самого создания или критический сбой Revit всё ещё могут помешать сохранению результата.

Для отладки используйте кнопку **«Выделить все элементы по…»** под выбором уровня: выберите кейс и нажмите «Выделить». Доступны Кейсы 1 и 2. Поиск охватывает текущую модель на всех уровнях, независимо от таблицы и активного вида. Экземпляры, соответствующие кейсу, включаются и при параметре уровня только для чтения. Инструмент показывает количество найденных и фактически выделенных объектов; при отсутствии совпадений сохраняет прежнее выделение. Закройте ReLevel, чтобы исследовать выбранные элементы в модели. Параметры модели не изменяются.

Рядом находится **«ReLevel инспектор»**. Нажмите кнопку: окно ReLevel закроется, после чего выберите один элемент в модели. Его свойства API, параметры экземпляра и типа, размещение, хост и зависимости добавятся в [ELEMENTS.md](ELEMENTS.md). После записи появится сообщение с ID, путём и числом ошибок чтения. Escape отменяет выбор без записи; для следующего элемента снова откройте команду. Можно выбирать элементы, ещё не охваченные кейсами переноса. Содержимое связанных моделей отдельно не выбирается.

Инспектор пишет в корень папки исходников, из которой собрана DLL; установленная копия использует тот же путь. При переносе этой папки пересоберите плагин. Записи накапливаются, прежние данные и заметки сохраняются; модель не изменяется. После записи можно попросить агента разобрать снимок и предложить следующий кейс. Поля отчёта имеют постоянные русские подписи и имена API независимо от языка интерфейса.

- Для проверки Кейса 2 выберите по очереди нижний и верхний уровни колонны: в таблице должна измениться подпись привязки. После переноса сравните видимое положение и длину, параметры обоих концов и проверьте Undo. Если колонна отсутствует в списке, снимите её инспектором: он показывает причины исключения, присоединения и соединения.

При ошибке сохранения соединений перенос автоматически применяет штатный Unjoin, если Revit разрешает его для этой ошибки. Успешный результат содержит `Unjoined` и ID участников, в том числе соседних объектов. Перенос и разъединение отменяются одним Undo. Если Unjoin недоступен или ошибка остаётся, операция элемента откатывается. Геометрия после разъединения может измениться; её следует проверить в Revit.

Кейс 8 пересоздаёт прямые Room Separation Lines на другом уровне с той же отметкой, сохраняя координаты и доступные заданные параметры. Требуется план этажа целевого уровня с фазой исходной линии. Оригинал удаляется вместе с внутренними зависимостями, в результате указан новый ID; вся замена отменяется одним Undo. Другие отметки, группы, варианты конструкции и внешние зависимости пока не поддерживаются.

Кейс 9 переносит лестницы класса Stairs с Base Level и Top Level: меняет привязки к исходному уровню и компенсирует смещения для сохранения абсолютных отметок и высоты. Лестница и её компоненты не пересоздаются. При Top Level=None переносится только нижняя привязка с компенсацией Base Offset, заданная высота не записывается. Многоэтажные лестницы пока не поддерживаются.

Кейс 10 переносит ограждения Railing без хоста через Base Level и компенсацию Base Offset. Ограждения на перекрытии Floor отбираются по собственному LevelId: плагин временно отсоединяет ограждение, меняет Base Level, возвращает прежний хост и исходный Base Offset в одной транзакции. Само перекрытие не переносится. Ограждения на лестницах и других классах хостов пока исключены. Offset from Path и конструкция ограждения отдельно не меняются. Если при переносе ограждения на Floor возникает ошибка недействительных ссылок размера (DimensionReferencesInvalid), плагин временно удаляет указанные Revit размеры, когда API разрешает это, и сообщает их ID в результате. Исправление размеров отложено; Undo отменяет перенос и удаление вместе. Другие неразрешимые ошибки вызывают полный откат. Результат нового варианта нужно проверить в Revit на копии модели.

Кейс 11 переносит трубы Pipe назначением только Reference Level. Смещения пересчитывает Revit; код не записывает уклон и геометрию и не отсоединяет концы. Закреплённые трубы, группы/сборки и readonly Reference Level исключаются. Гибкие трубы, FabricationPart, фитинги и арматура требуют отдельных кейсов.

## Ограничения

- Первый случай охватывает одноуровневые семейства с точечным размещением по условиям SPEC. Перенос с ненулевым смещением, поворотом, отказом API и Undo нужно проверить вручную на копии проекта; результат записать в TASKS.
- Кейс 2 охватывает вертикальные несущие (Structural Columns) и архитектурные (Columns) колонны TwoLevelsBased без присоединённого низа (ColumnAttachment), coping, void-вырезов и соединений концов, а также вертикальные Basic/Curtain Wall без присоединённого низа (присоединённый верх допускается), с верхним уровнем или непривязанной высотой. Составные стены и их части, группы и сборки не включены. Присоединённый верх несущей колонны допускается: меняется только Top Level, Top Offset пересчитывает Revit; свободный низ переносится с компенсацией смещения. У архитектурной колонны с присоединённым верхом разрешён перенос только низа, если верхний уровень отличается от исходного; перенос самого присоединённого верха пока исключён. Аналитическая связь допускается: переносится физическая колонна, аналитические элементы и ассоциация отдельно не редактируются. Зависимости, JoinGeometry и твердотельные вырезы сами по себе не исключают колонну; зависимости стены также не блокируют её отбор. Соединения и вырезы колонны отдельно не редактируются. Элементы сетки витража (панели, двери в ячейках и импосты) пересчитываются Revit без отдельного перемещения. Восстановление размещения обычных непосредственных хостовых семейств поддерживает LocationPoint; другой способ размещения или отказ восстановления прерывает перенос этой стены. Закреплённые экземпляры и недоступные изменяемые параметры исключаются. Геометрия и изменения других объектов при переносе не анализируются.
- Кейс 3 охватывает точечные WorkPlaneBased-семейства на грани локального хоста с доступными для записи Schedule Level и Elevation from Level. Связанные хосты, свободные рабочие плоскости, вложенные экземпляры, группы и сборки пока не включены. Перенос хоста и пересоздание семейства не выполняются.
- Кейс 7 охватывает прямые балки CurveDrivenStructural с хостом-уровнем Reference Level или без хоста. При заблокированном уровне временное изменение смещений концов снимает связь с рабочей плоскостью; прежняя связь не восстанавливается. Неудачная попытка и перенос откатываются вместе. Положение и соединения требуют проверки в Revit.
- Кейс 6 охватывает крыши по контуру FootPrintRoof с Cutoff Level = None. Меняются только Base Level и Base Offset From Level. Крыши с заданным уровнем среза пока не включены.
- Кейс 5 охватывает крыши выдавливанием ExtrusionRoof категории Roofs. Меняются Reference Level и Level Offset; профиль и границы выдавливания отдельно не редактируются. Крыши по контуру описаны в Кейсе 6.
- Кейс 4 охватывает перекрытия и фундаментные плиты класса Floor категорий Floors и Structural Foundations. Фундаменты других классов пока не включены. Меняются уровень и смещение; эскиз, толщина и форма отдельно не редактируются.
- Для видов проверяются доступные текст, значения, положение и ссылки аннотаций. Форматирование фрагментов текста, некоторые выноски, ссылки на скопированные объекты вида и недоступные свойства остаются ручной проверкой с явным замечанием в журнале. Созданный вид и число скопированных объектов не означают полную проверенность результата. Правила диапазона/подложки и побочных изменений сохраняются до решений D1/D2 в Tasks.
- Удаление элементов и видов сначала проверяется в откатываемой транзакции. Подтверждение показывает полный состав удаления с зависимостями. Уровни нельзя удалить, в том числе через зависимости. Зависимые виды и виды с зависимыми видами отклоняются. Для вида разрешено удаление его содержимого и размещений на листах; для элемента — подтверждённых зависимостей, кроме уровней и видов. Изменившийся состав, предупреждения Revit или посторонние изменения откатывают попытку.
- Пустая таблица элементов не означает, что уровень освобождён от зависимостей.

Unit-тесты не используются. Сборка не подтверждает поведение WPF/Revit API. Перед использованием проверьте на копии модели интерфейс, открытие и пересоздание видов, настройки и содержимое, журнал, удаление видов с зависимостями и Undo. Автоматических интеграционных тестов и проверенной тестовой RVT-модели нет.

Кейс 12 переносит площадки Pads (BuildingPad): меняет Level и компенсирует Height Offset From Level разницей отметок уровней. Закреплённые площадки, группы/сборки и недоступные для записи параметры исключаются. Площадка и её эскиз не пересоздаются.

Кейс 13 переносит воздуховоды Ducts назначением только Reference Level, как Pipes. Смещения пересчитывает Revit; код не меняет геометрию и не отсоединяет коннекторы. Закреплённые воздуховоды, группы/сборки и readonly Reference Level исключаются. FlexDuct, FabricationPart, фитинги, арматура и воздухораспределители этим кейсом не переносятся.

Кейс 2 также допускает геометрически вертикальные Structural Columns в режиме Slanted — End Point Driven. Плагин меняет привязки к исходному уровню с компенсацией смещений; Column Style и LocationCurve не назначаются. Фактически наклонные колонны и Angle Driven пока исключены. Новый вариант требует проверки положения концов и Undo в Revit.

Кейс 14 переносит шахтные проёмы Opening (Shaft Openings) с привязанными низом и верхом. Меняются только привязки к исходному уровню; смещения компенсируют разницу отметок уровней. Контур, эскиз и зависимости отдельно не редактируются. Непривязанный верх и другие категории проёмов пока исключены. Проверить положение, вырезы, размеры и Undo на копии модели.

Кейс 15 переносит пандусы категории Ramps с привязанными низом и верхом и Multistory Top Level=None. Меняются только привязки к исходному уровню, со смещениями для сохранения абсолютных отметок. Контур, уклон, толщина и зависимости отдельно не редактируются. Непривязанный верх и многоэтажные пандусы пока исключены. Положение, форму, размеры и Undo нужно проверить на копии модели.

Кейс 16 переносит нижнюю привязку внутренних стен хостовых семейств In-Place с компенсацией Base Offset. Для скрытых объектов нажмите «Добавить по ID» и введите номера, затем выберите исходный уровень, отметьте строки и используйте «Перенести элементы». ID не зашиты в плагин; автоматический поиск всех внутренних стен пока не реализован. Верх, внешние стены и вырезы отдельно не меняются. Введённые ID хранятся до закрытия окна; выделение Revit для переноса не требуется. Проверить работу основного плагина и Undo на копии модели.

Кейс 17 пересоздаёт Rooms на целевом уровне с новым ID, сохраняя фазу, X/Y, абсолютные высоты и заданные доступные параметры. Исходник удаляется в той же транзакции. Not Placed остаются неразмещёнными записями без нижней связи с исходным уровнем. Площадь и объём пересчитывает Revit. Для размещённых помещений нужен план и топология целевого уровня в исходной фазе. Помещения с марками, группой, сборкой, вариантом конструкции или закреплением пока исключены. Проверьте перенос и Undo на копии модели.

Кейс 18 пересоздаёт прямые Area Boundary Lines на другом уровне той же отметки, сохраняя XYZ, схему площади и заданные доступные параметры. План площадей нужной схемы используется или создаётся автоматически. Исходная линия удаляется после создания замены в той же транзакции; результат содержит новый ID и ID созданного плана. Один Undo отменяет перенос одной линии. Перенос на другую высоту пока не поддерживается. Проверенный пример: LEVEL 0 → Level LL.
