# ReLevel

Плагин Autodesk Revit 2025, .NET 8, Windows x64. Работа с элементами уровня или исходным выделением и видами уровня. Перенос использует существующие ограниченные стратегии и проверки геометрии. **Поведение новой версии непосредственно в Revit пока не проверено.**

## Сборка и установка

Нужны .NET SDK 8 или новее и Revit 2025. В Visual Studio 2022 нужен компонент разработки классических приложений .NET.

```powershell
dotnet build ReLevel.sln -c Release
```

Один проект создаёт одну DLL плагина: `src/ReLevel.Revit/bin/Release/net8.0-windows/ReLevel.Revit.dll`. Unit-тесты и отдельная сборка Core не используются.

API берётся из `C:\Program Files\Autodesk\Revit 2025`. Другой каталог: `-p:RevitInstallDir="D:\Autodesk\Revit 2025"`. При отсутствии API сборка выдаёт ошибку. Сборки Autodesk не копируются в комплект плагина.

Ручная установка при закрытом Revit:

1. Скопируйте `ReLevel.addin` из корня репозитория в `%APPDATA%\Autodesk\Revit\Addins\2025`.
2. Создайте в этом каталоге папку `ReLevel` и поместите в неё собранную `ReLevel.Revit.dll`. Манифест уже указывает этот относительный путь.
3. При обновлении замените DLL. Старая `ReLevel.Core.dll` больше не нужна.

Команда: **Надстройки → Внешние инструменты → ReLevel**.

## Интерфейс

Окно открывается по центру экрана с начальным размером 920 × 607,2 единицы WPF. Кнопки под таблицами расположены справа. Чек-бокс в заголовке отмечает все строки или снимает отметки; частичная отметка показана промежуточным состоянием. Если выделить несколько строк через Ctrl/Shift и нажать галочку одной из них, новое состояние применяется ко всему выделению. Пробел на чек-боксе работает так же.

Верхняя строка: «Уровень» и «Работать с выбранными элементами». Выделение запоминается при запуске команды. Без него переключатель недоступен. При включении список уровней очищается и блокируется, вкладка «Виды» недоступна. При выключении нужно снова выбрать уровень. Смена режима/уровня сбрасывает отметки и результаты строк.

**Элементы:** отметка, ID, категория, `Element.Name`, статус/причина; в режиме выделения дополнительно уровень (или несколько обнаруженных связей). Отмеченные строки можно выделить в Revit, удалить после подтверждения или перенести через диалог целевого уровня. Отметка отличается от обычного выделения строки таблицы. Кнопки неактивны без отметок. Результаты выводятся по ID, включая объекты, исчезнувшие из таблицы после операции. Перенесённые, пропущенные и ошибки подсчитываются отдельно.

**Виды:** нешаблонные виды с `GenLevel`, равным выбранному уровню; отметка, ID, имя и тип вида. Отмеченные виды можно последовательно открыть (последний становится активным) или удалить после подтверждения. «Пересоздать виды» создаёт планы этажей, потолков и конструкций на другом уровне с префиксом имени, настройками, шаблоном, секущим диапазоном и аннотациями. Исходные виды и их размещения на листах сохраняются; новые виды на листы не размещаются. Ограничения и ручные проверки: [VIEWS.md](VIEWS.md).

Поиск в обеих таблицах работает по видимым колонкам без учёта регистра. Стрелки и Enter/Shift+Enter переходят между совпавшими строками, «Фильтр» оставляет только совпадения. Пустой запрос показывает все строки. Общая отметка и операции применяются только к видимым строкам; скрытые отметки сохраняются до обновления данных, но не участвуют в операциях.

Состояние существует только в памяти окна. Закрытие окна не отменяет выполненные операции; отмена — через Undo Revit. История автоматически не записывается в файлы или параметры проекта. Журнал пересоздания видов можно явно сохранить в `.txt`.

Пересоздание сохраняет новый вид до копирования настроек и содержимого. Ошибки последующих этапов и диагностические замечания показываются в отдельном журнале и обычно не отменяют вид. В журнале доступны исходные ID проблемных элементов, подробности Revit, поиск, копирование, сохранение и открытие нового вида. Ошибка самого создания или критический сбой Revit всё ещё могут помешать сохранению результата.

## Ограничения

- Сохранён поиск элементов модели текущего документа, не специфичных для вида, по `Element.LevelId` и известным параметрам базового/опорного уровня в `TransferAnalyzer.IsOnLevel`. Верхние ограничения, все косвенные связи и связанные RVT не охвачены. В режиме выделения показываются существующие элементы исходного выделения без этого фильтра.
- Перенос реализован для некоторых одноуровневых точечных семейств без хоста, горизонтальных перекрытий/потолков и прямых неприсоединённых стен. Условия перечислены в [CATEGORIES.md](CATEGORIES.md). Наличие строки не означает поддержку переноса. MEP и универсальный перенос не реализованы.
- Алгоритмы переноса не менялись: компенсация смещения, отдельные транзакции, проверка геометрии до/после фиксации и откат при побочных изменениях. Предварительный анализ не гарантирует успеха.
- Удаление сначала проверяется в откатываемой транзакции. Подтверждение показывает количество отмеченных объектов и полный состав удаления с зависимостями. Уровни нельзя удалить, в том числе через зависимости. Зависимые виды и виды с зависимыми видами отклоняются. Для вида разрешено удаление его содержимого и размещений на листах. Изменившийся состав, предупреждения Revit или посторонние изменения откатывают попытку; часть удалений может быть отклонена.
- Уровни и виды из исходного выделения видны в «Элементах», но удалить уровень нельзя, а удаление вида выполняется только на вкладке «Виды».

## Основные файлы

```text
ReLevel.sln                              решение с одним проектом
ReLevel.addin                            манифест регистрации команды
src/ReLevel.Revit/
  ReLevel.Revit.csproj                    .NET 8/WPF и ссылки на API 2025
  ReLevelCommand.cs                       вход в команду, исходное выделение
  Logic/LevelTransfer.cs                  смещение, координаты, результаты
  DeleteService.cs                        проверка зависимостей и удаление
  UI/TransferWindow.cs                    окно, таблицы и операции
  UI/RecreateViewsWindow.cs               уровень и префикс для новых видов
  UI/TableSearch.cs                      поиск, фильтрация и переходы по таблице
  UI/TableRow.cs                          данные строки и отметка
  UI/OperationDialogs.cs                  цель, подтверждения и результаты
  Transfer/Strategies.cs                  стратегии и поиск по уровню
  Transfer/TransferService.cs             перенос и откат
  Transfer/ViewRecreationService.cs       пересоздание планов и откат
  Transfer/ViewSettingsSnapshot.cs        параметры, диапазон и обрезка
  Transfer/ViewGraphicsSnapshot.cs        видимость, графика и фильтры
  Transfer/ViewAnnotations.cs             копирование и проверка аннотаций
  Transfer/GeometrySnapshot.cs            проверка геометрии
docs/SPEC.md                             требования и границы реализации
CATEGORIES.md                            алгоритмы и условия переноса элементов
VIEWS.md                                 правила и алгоритмы переноса видов
```

Unit-тесты не используются. Сборка не подтверждает поведение WPF/Revit API. Перед использованием проверьте на копии модели перенос между уровнями с сохранением координат и геометрии, пропуск неподдерживаемых элементов, выделение, открытие видов, удаление с зависимостями и отмену операций. Автоматических интеграционных тестов и проверенной тестовой RVT-модели нет.
