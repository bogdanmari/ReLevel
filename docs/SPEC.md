# Спецификация ReLevel

Плагин Revit 2025 для работы с элементами и видами уровней. Перенос элементов сохраняет положение и геометрию. Цель развития — расширять поддержку категорий и механизмов по [CATEGORIES.md](../CATEGORIES.md), а также пересоздавать виды на другом уровне по [VIEWS.md](../VIEWS.md). Полный охват пока не реализован; новые механизмы добавляются отдельными задачами.

## Текущее состояние

Работают выделение, удаление и перенос поддерживаемых элементов, открытие и удаление видов. Поиск и фильтрация работают в обеих таблицах. Пересоздание планов этажей, потолков и конструкций реализовано с ограничениями из VIEWS.md; внутри Revit пока не проверено. Сборка не подтверждает поведение в Revit; автоматических интеграционных тестов и проверенной RVT-модели нет.

## Окно и таблицы

- WPF-окно 920 × 607,2, по центру экрана. Сверху — уровень и переключатель «Работать с выбранными элементами»; ниже — вкладки «Элементы» и «Виды».
- Исходное выделение запоминается при запуске. Без него переключатель недоступен. В режиме выделения список уровней очищен и заблокирован, вкладка видов недоступна; при выходе уровень выбирается заново.
- Смена режима/уровня обновляет таблицы и сбрасывает отметки. Состояние хранится только в памяти окна, без файлов истории и параметров проекта.
- Общий чек-бокс отмечает все строки и показывает частичную отметку. Ctrl/Shift выделяют строки; чек-бокс или пробел на выделенной строке применяют отметку ко всему выделению, на невыделенной — только к ней.
- Кнопки операций справа под таблицей, недоступны без отметок. После операций таблицы обновляются, отметки сбрасываются, результат выводится по ID, в том числе для исчезнувших строк.
- Поиск по подстроке без учёта регистра охватывает видимые текстовые колонки, включая ID. Счётчик считает совпавшие строки; стрелки и Enter/Shift+Enter переходят по ним циклически в порядке таблицы. Переход выделяет строку, но не ставит отметку.
- «Фильтр» переключает показ только совпадений; пустой запрос показывает всё. Запрос и режим фильтра сохраняются при обновлении таблицы. Общий чек-бокс и операции действуют только на видимые строки; отметки скрытых строк сохраняются до обновления данных, но в операциях не участвуют.

## Элементы

По уровню выбираются элементы модели текущего документа, не принадлежащие виду: поиск по `LevelId` и известным параметрам базового/опорного уровня. Это не полный поиск связей. В режиме выделения показываются сохранившиеся элементы исходного выделения.

Колонки: отметка, ID, категория, имя, статус/причина; в режиме выделения — также найденные уровни или «Не определён».

- **Выделить** — установить выделение Revit, сохранив исходный список окна.
- **Удалить** — после проверки зависимостей и подтверждения. Виды удаляются через свою вкладку.
- **Перенести** — выбрать целевой уровень. В режиме уровня источник исключён из целей; элементы, уже находящиеся на цели, пропускаются. Отчёт различает успешные переносы, пропуски и ошибки.

Механизмы, ограничения, допуски и откат описаны в [CATEGORIES.md](../CATEGORIES.md). Наличие строки в таблице не означает поддержку переноса.

## Виды

Показываются нешаблонные виды, у которых `GenLevel` совпадает с выбранным уровнем. Колонки: отметка, ID, имя, тип.

- **Открыть** — последовательно открыть отмеченные виды, сообщить ошибки по ID.
- **Удалить** — с подтверждением содержимого и зависимостей. Зависимые виды и виды с зависимыми видами отклоняются.
- **Пересоздать** — выбрать другой уровень и префикс, создать планы с исходными настройками и аннотациями. Секущий диапазон копируется без пересчёта. Исходные виды и листы сохраняются. Ограничения и проверки — в [VIEWS.md](../VIEWS.md).
- Новый вид фиксируется до переноса настроек, графики и аннотаций. Настройки и графика переносятся отдельными транзакциями; их ошибки не отменяют создание. Для Scope Box назначается та же область видимости. Проверки настроек и графики являются диагностическими.
- Аннотации, включая высотные отметки, копируются средствами Revit по одной без дополнительного смещения. Неудачная вставка откатывается отдельно; отсутствие результата записывается с исходным ID. Габариты, положение, содержимое и ссылки не сравниваются. Предупреждения Revit журналируются и снимаются для продолжения; ошибки, запрещающие фиксацию, отменяют только текущий этап. Изменения существующих объектов перечисляются по ID без общего отката. Вид сохраняется с неполным содержимым. Критический сбой регенерации/транзакции всё ещё может отменить пакет. Одна операция Undo сохраняется.
- Результат пересоздания показывается в отдельном журнале: сводка, уровень сообщения, этап, ID исходного/нового вида и исходного элемента, описание, рекомендация и технические подробности. Есть поиск, фильтр замечаний/ошибок, копирование записи/всего журнала, сохранение `.txt` и открытие нового вида. Проверка окна и нового поведения в Revit ещё требуется.

## Удаление и сохранение результата

Предварительное удаление выполняется с откатом. Реальное допускается только при совпадении состава и отсутствии побочных изменений; уровни защищены и от косвенного удаления. Подтверждение по умолчанию предлагает отмену. Ошибки показываются явно, частичные изменения откатываются.

Сбор объектов для проверки зависимостей удаления и диагностики изменений при пересоздании видов использует обязательный фильтр Revit API, включающий экземпляры и типы элементов. Смягчённая обработка ошибок пересоздания не изменяет защиту удаления и переноса элементов.

Закрытие окна сохраняет завершённые операции; отмена выполняется через Undo Revit. Архитектура и процесс разработки — в [AGENTS.md](../AGENTS.md), сборка и установка — в [README.md](../README.md).
