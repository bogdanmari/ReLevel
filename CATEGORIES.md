# Методы переноса и категории ReLevel

Документ описывает текущую реализацию, а не поддержку всех элементов перечисленных категорий. Каждый экземпляр проходит проверки ниже. Поведение в Revit в рамках этой задачи не проверялось; основные ручные проверки перечислены в [README.md](README.md).

## Общий принцип

Все реализованные методы меняют параметр уровня и компенсируют разницу отметок параметром смещения:

`Новое смещение = Старое смещение + Отметка исходного уровня − Отметка целевого уровня`.

Используется `Level.ProjectElevation`; вычисления выполняются во внутренних единицах Revit (футах). Например, при исходной отметке 0 мм, смещении +1200 мм и целевой отметке +3000 мм новое смещение равно −1800 мм.

Параметры уровня и смещения записываются в одной транзакции без промежуточной регенерации. После записи выполняются регенерация и проверки, затем повторные проверки после фиксации транзакции.

## 1. Точечные одноуровневые семейства без хоста

Реализация: `PointFamilyStrategy` в [Strategies.cs](src/ReLevel.Revit/Transfer/Strategies.cs).

| Категория | BuiltInCategory |
| --- | --- |
| Мебель | `OST_Furniture` |
| Мебельные системы | `OST_FurnitureSystems` |
| Столярные изделия | `OST_Casework` |
| Обобщённые модели | `OST_GenericModel` |
| Специальное оборудование | `OST_SpecialityEquipment` |
| Озеленение (Planting) | `OST_Planting` |
| Антураж (Entourage) | `OST_Entourage` |
| Генплан (Site), только экземпляры семейств | `OST_Site` |

Метод меняет `FAMILY_LEVEL_PARAM` и пересчитывает `INSTANCE_ELEVATION_PARAM`.

Допускаются только экземпляры `FamilyInstance` загружаемых семейств с типом размещения `OneLevelBased` и положением `LocationPoint`. Исключаются контекстные семейства, экземпляры с хостом, родительским компонентом, вложенными общими компонентами или непустым `MEPModel`. Одного совпадения категории недостаточно.

## 2. Горизонтальные плоские перекрытия и потолки

Реализация: `HorizontalHostStrategy` в [Strategies.cs](src/ReLevel.Revit/Transfer/Strategies.cs), с настройкой для перекрытия или потолка.

| Категория | Класс Revit | BuiltInCategory | Параметр уровня | Параметр смещения |
| --- | --- | --- | --- | --- |
| Перекрытия | `Floor` | `OST_Floors` | `LEVEL_PARAM` | `FLOOR_HEIGHTABOVELEVEL_PARAM` |
| Потолки | `Ceiling` | `OST_Ceilings` | `LEVEL_PARAM` | `CEILING_HEIGHTABOVELEVEL_PARAM` |

Выбор метода выполняется по классу элемента. Меняется уровень и компенсируется смещение соответствующего хоста.

Верхние грани должны существовать, быть плоскими и горизонтальными. Для перекрытия дополнительно требуется доступный редактор формы с `IsEnabled == false`. Элементы со вставками, возвращаемыми `FindInserts(true, true, true, true)`, пропускаются. Наклонные перекрытия и перекрытия с включённым редактированием формы не поддерживаются.

## 3. Прямые вертикальные стены без верхней привязки

Реализация: `UnconnectedWallStrategy` в [Strategies.cs](src/ReLevel.Revit/Transfer/Strategies.cs).

| Категория | BuiltInCategory |
| --- | --- |
| Стены | `OST_Walls` |

Метод меняет нижний уровень `WALL_BASE_CONSTRAINT` и пересчитывает нижнее смещение `WALL_BASE_OFFSET`. Параметры высоты и верха метод не записывает; сохранение формы проверяется по геометрии.

Допускаются только базовые стены (`WallKind.Basic`) с вертикальным сечением, прямой `LocationCurve` и без изменённого профиля. Стена не должна быть членом составной стены, иметь верхний уровень, присоединение сверху или снизу, вставки, проёмы либо соединения с другими стенами на концах.

## Общие ограничения и проверки

Для всех методов предварительный анализ пропускает закреплённые элементы, элементы групп и сборок, элементы вариантов конструкции и элементы с объединённой геометрией. Параметры уровня и смещения должны иметь нужные типы и быть доступны для записи; смещение должно иметь значение, исходный уровень должен определяться. Элемент, уже привязанный к целевому уровню, пропускается.

Перед изменением сохраняется снимок состояния. [GeometrySnapshot.cs](src/ReLevel.Revit/Transfer/GeometrySnapshot.cs) сравнивает:

- тип элемента;
- точку размещения и угол поворота для `LocationPoint`;
- точки тесселяции кривой для `LocationCurve`;
- минимальную и максимальную точки габаритов в координатах модели;
- точки геометрии, объёмы и площади поверхностей твёрдых тел.

Допуск координат — `1e-5` фута (примерно 0,003 мм); угла — `1e-9` радиана. Для объёмов и площадей используется `max(1, |исходное значение|) × 1e-9` во внутренних единицах соответствующей величины. Сравнение точек учитывает порядок перечисления, поэтому изменение тесселяции также может привести к отказу. Без габаритов или твёрдотельной геометрии перенос не выполняется.

[TransferService.cs](src/ReLevel.Revit/Transfer/TransferService.cs) дополнительно проверяет целевой уровень и рассчитанное смещение. Предупреждения и ошибки Revit, изменение других элементов, добавление или удаление элементов во время фиксации транзакции приводят к откату попытки. Обычная ошибка одного элемента не отменяет успешные независимые переносы; критическая ошибка, включая сбой регенерации, отменяет пакет целиком.

## Пока не поддерживается

Для остальных категорий стратегии не зарегистрированы. В частности, нет методов для MEP-элементов, семейств на хостах или гранях, колонн, балок, крыш и лестниц. Обнаружение элемента при поиске по исходному уровню не означает возможности его переноса.

Текущий снимок состояния не проверяет MEP-коннекторы и системные соединения. Добавление таких элементов требует соответствующего метода и проверок, а не только расширения списка категорий.

В сохранённом `Report.txt` разобрано 1348 строк элементов: 33 «Готов», 1315 «Пропуск». Это предварительный анализ: статус «Готов» не подтверждает выполненный перенос. В отчёте нет значений параметров, типа размещения семейства, данных о хостах, геометрии и состоянии после переноса.

### Расширение метода 1 по отчёту

| Planting | 288 | 225 | 63 в вариантах конструкции | 6807469, 6813188, 6814619 |
| Entourage | 4 | 4 | Нет | 7147832, 7148543, 7149258 |
| Site | 3 | 3 | Нет | 13533540, 13533541, 13589291 |

232 экземпляра ранее отклонялись из-за отсутствия стратегии; это не прогноз числа успешных переносов. Экземпляры в вариантах конструкции по-прежнему пропускаются. Для Enscape-ассетов, RPC и других семейств без доступной твёрдотельной геометрии текущая проверка отклонит попытку до записи параметров. Категория Site не включает автоматически Pads и другие системные элементы участка.

Анализатор сообщает первую найденную причину. Устранение этой причины не гарантирует допуска к переносу. Закрепление, варианты конструкции и ограничения существующих методов не снимаются этим расширением.

Для дальнейшего расширения нужны диагностические данные хотя бы одного представителя каждого механизма: Id, класс и BuiltInCategory, FamilyPlacementType, параметры уровней/смещений с признаком доступности записи, хосты, зависимости и коннекторы. Для проверки результата нужны исходный и целевой уровни, состояние до/после и итоговый отчёт операции. Наличие параметра уровня само по себе не подтверждает безопасный перенос.
