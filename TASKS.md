# ReLevel — задачи разработки

## Как пользоваться

- Требования находятся в [SPEC](docs/SPEC.md); правила разработки — в [AGENTS](AGENTS.md).
- Здесь фиксируются оставшаяся работа, вопросы и фактически выполненные проверки.
- Статусы: «К выполнению», «В работе», «Проверить в Revit», «Готово», «Нужно решение».
- При общей команде продолжить разработку выбирать первую незаблокированную задачу. Задачи со статусом «Нужно решение» не реализовывать без согласования поведения.
- Сборка подтверждает компиляцию. Результат ручной проверки записывать с версией Revit и проверенными случаями.
