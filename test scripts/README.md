# Диагностика Area

`inspect_areas.py` запускается целиком через RevitPythonShell в открытом проекте Revit 2025. Выделять Area и искать вид не требуется. Скрипт только читает модель, транзакций нет.

Он находит уровни `LEVEL LL` и `LEVEL 0` по имени без учёта регистра; собирает все Area этих уровней плюс пример `2219718`, их схемы, параметры, расположение, контуры границ с ID образующих элементов, зависимости и марки. Находит Area Plan для обоих уровней и перечисляет исходные схемы без плана на целевом уровне. Названия уровней можно изменить в константах SOURCE_NAME/TARGET_NAME.

Отчёт: `reports/areas_*.json`. Путь выводится в консоль. Ошибки отдельных чтений отмечаются `read_error`, общая ошибка — `error`. Список уровней сохраняется даже при неоднозначном/отсутствующем имени. Геометрия границ представлена точками Tessellate для диагностики, не для восстановления точной кривой. Скрипт не проверяет возможность переноса и не изменяет площади, планы, границы или марки.

# Проба пересоздания Room Separator

`recreate_room_separator.py` проверяет замену линии `22043147` новой Room Separation Line с переносом доступных параметров. Запускается целиком в RevitPythonShell; рядом должен находиться `change_room_separator_plane.py` (общие функции, прежняя проба при импорте не запускается).

- Введите ID или точное имя целевого уровня, например `30` / `LEVEL 0` для текущего проекта. Эта первая проба допускает только совпадающие отметки уровней и сохраняет XYZ. Нужен существующий план этажа целевого уровня с фазой исходной линии; если его нет, скрипт объяснит причину остановки.
- Новая линия получает рабочий набор, фазы и остальные доступные для записи заданные параметры исходника. Вычисляемые/readonly значения только читаются. Несовпадения попадают в отчёт.
- Оригинал временно удаляется, чтобы собрать реальный состав удаления. **Вся проба всегда откатывается**, даже при успешном Commit: после запуска в модели остаётся исходная линия. Поэтому эта версия предназначена для отчёта, а не визуального осмотра сохранённой замены.
- Отчёт `reports/room_recreate_22043147_*.json`: `parameter_copy`, `parameters_before/after`, `parameter_differences`, `deleted_elements`, `failures`, `group_rollback`. При нормальном завершении группы последнее поле должно быть `RolledBack`.

По первому отчёту создание и запись параметров прошли, но Commit откатился из-за предупреждений о пересечении разделителя со стенами. Обновлённая проба сохраняет в `failures` и снимает только это предупреждение (GUID `f7b3a015-c3eb-4a3f-b345-c474ec07d43f`), чтобы прочитать результат после Commit. Другие предупреждения и ошибки приводят к откату транзакции. Успешный Commit всё равно отменяется внешней группой; снятие предупреждения не исправляет наложение и не доказывает правильность границ помещений.

Пересоздание включено в плагин как Кейс 8 для прямых линий между уровнями на совпадающих отметках. C#-реализацию ещё требуется проверить в Revit; проба остаётся отдельным инструментом сравнения параметров и зависимостей. Новый ID и новый SketchPlane отличаются от исходных.

Отчёт 01.10.2026 `173101_8e03c467` подтвердил успешный Commit для 22043147 → LEVEL 0 в Revit 2025 build 25.4.41.14: четыре доступных параметра совпали, LevelId новой линии равен 30. Единственное различие снятых параметров — вычисляемая длина примерно на 0.000002432 mm. Группа затем успешно откатилась. Сохранность границ помещений и результат удаления исходного уровня этим отчётом не проверены.

# Проба рабочей плоскости Room Separator

`change_room_separator_plane.py` запускается целиком через RevitPythonShell в Revit 2025 на копии модели. Он работает строго с ID `22043147`, независимо от выделения.

1. Откройте скрипт в редакторе RevitPythonShell и выполните его.
2. Введите ID целевого уровня или его точное имя. Список уровней выводится в консоль. Cancel отменяет изменение.
3. Скрипт создаёт SketchPlane на целевом уровне и назначает его существующей линии через `line.SketchPlane`. Уровни, старая плоскость и линия не удаляются; геометрия кривой отдельно не записывается. При разных отметках уровней линия может переместиться по высоте — это часть проверяемого поведения.
4. Успешный Commit **остаётся в модели**, его можно отменить одним Undo. При предупреждении/ошибке Revit транзакция откатывается, автоматические исправления не применяются.
5. Проверьте положение линии, границы/площади помещений и на копии модели — сохранится ли линия после удаления исходного уровня. Сам скрипт уровень не удаляет. Если проверяли удаление, сначала отмените его отдельным Undo.

Отчёт `reports/room_plane_22043147_*.json` содержит плоскость, LevelId, координаты, длину и зависимости до/после, статус транзакции и сообщения Revit. Если после успешного Commit не удалось прочитать снимок или записать файл, это само по себе не отменяет изменение; смотрите статус/сообщения консоли. При отсутствии `__file__` используется `PROJECT_SCRIPT_DIR`. Запуск нового скрипта в Revit ещё не проверен.

Результат пробы Room Separator от 01.10.2026: Revit 2025 build 25.4.41.14 запретил назначение SketchPlane линии 22043147 (`Changing the SketchPlane of this CurveElem is not allowed`). Транзакция откатилась. В отчёте 140919_2f1f3e81 поле `status` осталось `NotStarted` из-за исключения до Commit; фактический итог указан в `rollback_status`: `RolledBack`. Скрипт сохранён как воспроизводимая проба этого ограничения.

# Диагностика оставшихся Model Lines

Откройте исходный проект в Revit 2025 и выполните целиком `inspect_model_lines.py` через редактор RevitPythonShell. Выделение и специальный вид не требуются: 26 ID со скриншота удаления уже записаны в `ELEMENT_IDS`. Размеры не исследуются; зависимости линий записываются только списком ID.

Скрипт только читает данные: категория, класс, параметры и ссылки параметров, кривая, стиль, SketchPlane с геометрией и ссылкой на основание, уровни, владелец, закрепление, группа и вариант конструкции. Изменений модели и пробного удаления нет. Отсутствующие ID попадают в `missing_ids`, ошибки чтения — в `read_error`; неправильный открытый проект может дать отсутствующие или посторонние элементы, поэтому проверьте `document` в отчёте.

Результат сохраняется в `test scripts/reports/model_lines_<дата>_<время>_<суффикс>.json`; полный путь выводится после `Report:`. При запуске без `__file__` используется `PROJECT_SCRIPT_DIR`. Перенос линий этим скриптом не выполняется; его алгоритм будет выбран после анализа отчёта.

# Диагностика соединений стены

`inspect_wall_joins.py` запускается целиком через RevitPythonShell в открытом проекте Revit 2025. Скрипт использует синтаксис, совместимый с Python 2.7/3.

Первый вариант проверен пользовательским отчётом от 01.10.2026 в Revit 2025 build 25.4.41.14: ошибка воспроизведена, транзакция и группа откатились. После анализа добавлен раздел `known_failure_participants`: для стены `10925001` заранее читаются ID `21941484`, `21941575`, `22051679`, `22051757`, указанные Revit. Также собираются существующие предупреждения для этих участников и ближайших соседей. Дополнение проверено отчётом `wall_10925001_20261001_115331_a3b2038d.json`: чтение прошло без ошибок, обнаружены существующие предупреждения о наложении пар стен 21941484/22051679 и 21941575/22051757. Для сбора без пробы нажмите Cancel в запросе целевого уровня. Анализ и оставшаяся проверка причины ошибки записаны в TASKS.md, R24.

1. Для разбора ошибки переноса откройте копию модели. Выделите одну стену. При пустом выделении используется ID `10925001`; несколько выделенных элементов отклоняются.
2. Откройте файл в редакторе RevitPythonShell и выполните весь скрипт.
3. Скрипт выведет уровни с ID в консоль и предложит необязательную пробу. Пустое поле или Cancel означает только чтение модели.
4. Чтобы воспроизвести ошибку, введите ID того же целевого уровня, что выбирали в ReLevel. Затем укажите исходный уровень; по умолчанию предлагается Base Constraint стены.
5. Скопируйте путь отчёта из строки `Report:`. UTF-8 JSON сохраняется в `test scripts/reports`; имя содержит ID стены, время и уникальный суффикс, прежние отчёты не перезаписываются.

Если редактор не задаёт `__file__`, используется путь проекта в константе `PROJECT_SCRIPT_DIR`. При переносе проекта исправьте эту константу. Отчёт содержит путь и название модели.

В отчёте: параметры стены и соседей, ограничивающая рамка, ось, соединения JoinGeometry с порядком вырезания, участники стыков обоих концов и разрешение соединений, зависимости, существующие предупреждения и список уровней. Ошибки чтения отмечаются `read_error`. Перечень соседей — один шаг от выбранной стены, без рекурсивного обхода модели.

Проба повторяет порядок записи пар уровня/смещения стены, совпавших с исходным уровнем. Она не выполняет Unjoin, не исправляет предупреждения и не меняет алгоритм плагина. Для стены с хостовыми семействами проба отклоняется: этап восстановления их точек здесь не воспроизводится. При предупреждении или ошибке транзакция откатывается; даже успешный Commit отменяется откатом внешней TransactionGroup. Статусы отката записываются в отчёт. При исключении записывается traceback; после сбоя регенерации чтение модели не продолжается.

Раздел `probe.failures` содержит точный текст, код, важность, `failing_ids` и `additional_ids` из сообщения Revit. Именно эти ID нужны для определения участников ошибки; перечень обычных соединений сам по себе не определяет виновника. Если ошибка не повторилась, это явно видно по отсутствию сообщений и статусу Commit — её причину нельзя считать установленной. Проба не воспроизводит весь пакет из 459 элементов и его порядок.
